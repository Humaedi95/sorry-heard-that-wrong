A tiny program that writes one line — the funniest apology a smart speaker gives after mishearing its owner — to `/output/entry.txt`.

Entry: "Sorry, I heard 'turn off the lights' as 'burn down the house.' I only dimmed them. You're welcome."

## Run

```sh
node main.ts
```
